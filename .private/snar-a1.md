Формат Skorpion Project Configuration (SPC) распространяется на файлы `manifest.spc`.

---

## Лексика
Лексика SPC содержит символы `[` (LBracket), `]` (RBracket), `"` (Quite), `'` (Apos), `\` (Backslach), `.` (Dot), `<` (Lt), `>` (Gt), `-` (Minus) и `,` (Comma), и типы значений **String**, **Int**, **Float**, **Bool** и **Array**

#### String
Тип String хранит значения в виде любой последовательности символов ASCII словаря любой длины, ограничивающейся лишь допустимой длиной значения и допустимыми символами значения конкретных параметров
Значения типа String обязательно заключены в `"` (Quote, VALUE, Quote) или `'` (Apos, VALUE, Apos)

#### Int
Int значения представляют собой значение состоящее только из цифр и, иногда, симовола `-` перед цифрой или цифровой последовательностью

#### Float
Float значения представляют собой значение состоящее из цифр, символа `.` (Dot), отделяющего целую и дробную части, и, иногда, симовола `-` (Minus) перед цифрой или цифровой последовательностью

#### Bool
Bool знчачения содержат `true` или `false`, никаких других значений у Bool типа нет

#### Array
Array является списком значений других типов, заключенный в открывающий `<` (Lt) и закрывающий `>` (Gt), при чем Ident не может быть значением Array
Между значениями Array обязательно ставится `,` (Comma), после последнего элемента `,` опциональна

#### Ident
Так же лексер позволяет писать Ident значения, они не заключены в скобки, кавычки, не содержат цифры (Разрешенный список символов Ident значений `A-Za-z`)

---

## Синтаксис

#### Параметр
Назначение параметра конфигурации (прямая обязанность SPC) происходит по паттерну `Param[Value]` (Ident, LBracket, VALUE, RBracket)
